# Engineering Practices

I aim to build applications with an emphasis on:

Organizing application logic into clear and understandable components to simplify future development.

### API Design

Building predictable RESTful endpoints with structured request and response formats.

### Testing

Testing application functionality and API endpoints to verify expected behavior and authorization rules.

### Deployment

Deploying applications to cloud and shared hosting environments depending on project requirements.

# Local Development

This repository contains the source code for the portfolio website.

## Requirements

* Node.js 18+
* npm
* Git

## Installation

Clone the repository:

```bash
git clone https://github.com/MasMuham24/Portfolio.git

cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

# Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
